# K5版 実機テスト計画

これは，DP32G030搭載の旧UV-K5向け`wrx-jp`を実機で確認するための試験票です．ホストテストやビルド成功は，RF性能，LCDの見え方，書き込み成功を保証しません．実施前に個体のEEPROM・calibration・全イメージを保存してください．

## 試験項目

| ID | 操作 | 期待結果 | 実測・判定 |
| --- | --- | --- | --- |
| SAFE-01 | バックアップを取得し，復元手順を確認する | EEPROM，calibration，全イメージを復元可能 | |
| ID-01 | 起動画面とバージョンを確認する | `JP RX-Only`，`Kris`，J版が表示される | |
| UI-01 | 起動画面のMESSAGE／ALLを確認する | `受信専用`が乱れず，版表示やメッセージと重ならない | |
| UI-02 | メニュー，ヘルプ，長音「ー」，欧文を表示する | 欧文と和文の基線，上下余白，右端切れが許容範囲 | |
| RX-01 | PTTを短押し・長押しする | 送信せず，モニターだけが切り替わる | |
| RX-02 | 送信要求に相当する操作を行う | ビープと`TX DISABLE`等の安全表示．送信波が出ない | |
| RX-03 | FM，NFM，AM，RXExtを切り替える | 各モードで受信音と表示が対応する | |
| BW-01 | W+／W／N／N-を順に選ぶ | 25／20／12.5／6.25 kHzの表示と受信幅が対応する | |
| STEP-01 | 周波数ステップを変更し，上下キーで移動する | 設定した刻みで周波数が変化し，保存・復元できる | |
| FM-01 | FM放送帯の76.0，76.1，94.9，95.0 MHzを入力する | 日本向け範囲と端点の扱いが一貫し，10 kHz刻みで選局できる | |
| FM-02 | 既知のFM局を複数受信する | ステレオ／モノラルを含め，受信音が途切れない | |
| SCAN-01 | バンドプリセットと範囲スキャンを実行する | 指定範囲だけを走査し，停止・再開ができる | |
| SCAN-02 | スキャン中に一時スキップを設定する | 対象だけを一時的に飛ばし，再起動後の仕様が説明どおり | |
| SQL-01 | 無信号，弱信号，強信号でスケルチを確認する | 開閉が極端に不安定でなく，逆CTCSSも意図どおり | |
| METER-01 | RSSI，音声レベル，AGCガード表示を確認する | 表示更新が崩れず，受信音を阻害しない | |
| MEM-01 | チャンネル名，バンク，プリセットを保存して再起動する | 設定が保持され，対象チャンネルが正しい | |
| CHIRP-01 | CHIRPで読み取りだけを行い，事前バックアップと比較する | 通常領域だけが読め，calibrationは変化しない | |
| CHIRP-02 | 変更を1件だけアップロードし，再読取する | 変更対象だけ反映し，calibrationが不変 | |
| POWER-01 | 電池低下・充電・再起動を確認する | 安全表示が出て，設定や受信状態が破損しない | |

## 不具合記録

写真または動画，表示版，操作列，再現回数，書き込み前バックアップの有無を記録します．送信波の有無は可能なら外部受信機または測定器でも確認し，確認できない場合は「未測定」と記載します．
