# フォント一覧

この一覧は `tools/render_bitmap_atlas.py` が現行Cソースから生成したものです。
コードはファームウェア内部の1バイトコードであり、Unicodeコードポイントではありません。
字形の元バイト列は同じ出力ディレクトリの `bitmap_atlas_inventory.json` を参照してください。
